1项目背景与业务目标

项目背景

大数据产业持续扩张，但岗位需求在区域、学历、经验、技能栈四个维度上分化明显。招聘平台信息高度分散且以非结构化文本为主，求职者难以凭零散经验回答三个现实问题：该去哪个城市、该学哪些技能、期望薪资定多少。本项目以公开招聘信息为研究对象，独立完成从数据采集到结论输出的全流程，用量化方式刻画岗位市场画像，既服务于个人求职决策，也作为数据分析工程能力的完整证明。

业务目标

目标说明
市场画像刻画大数据岗位的城市分布、学历与经验门槛结构
技能图谱提炼高频技能与技能组合，明确学习优先级
薪资量化量化城市 / 学历 / 经验对薪资的影响，校准薪资预期
赛道选择区分数仓 / 数开 / 分析 / 平台运维四类方向的需求与薪资差异
方法论沉淀形成可复用的"采集—清洗—分析—可视化"工程闭环

2项目整体流程架构

采用五层数据流水线，每层职责单一、产出可验证：

① 数据采集层   Requests + BeautifulSoup     robots 校验 / 限速 / 断点续采
      ↓
② 数据存储层   CSV 原始层 + SQLite 标准层    原始可回溯 / 分层解耦
      ↓
③ 数据清洗层   pandas + 正则 + jieba        去重 / 缺失 / 归一化 / 标签抽取
      ↓
④ 数据分析层   pandas + NumPy               描述统计 / 分组对比 / 技能共现
      ↓
⑤ 可视化交付层 matplotlib + ECharts         图表 / 交互式报告 / 作品集页面
层级核心工作关键技术
① 采集关键词检索、分页遍历、字段抽取、异常重试Requests、BeautifulSoup、robots 校验、随机延时
② 存储原始层（CSV）与标准层（SQLite）分离CSV 追加写、断点续采、SQLite 建表入库
③ 清洗去重、缺失处理、薪资标准化、维度归一化、技能抽取pandas、正则表达式、jieba + 技能词典
④ 分析分布统计、分组对比、相关性分析、词频与共现groupby / pivot、NumPy、共现矩阵
⑤ 可视化静态图表、交互式仪表盘、结论报告matplotlib（中文渲染）、ECharts、自包含 HTML
关键工程点：采集前校验 robots 协议；原始层只追加不修改，保证可回溯；清洗逻辑脚本化，可重复执行。

3数据源说明

项目说明
数据来源主流招聘平台公开岗位列表页（BOSS 直聘、智联招聘、猎聘等），辅以平台公开行业报告做交叉校验
采集范围关键词：大数据、数据开发、数据仓库、ETL、数据分析、数据平台；城市：北上广深杭成等 15 个主要城市
样本规模原始记录 5,000–10,000 条，清洗后有效样本不低于 4,000 条（按城市 × 关键词分层采集）
时间窗口连续 3 个月滚动采集，形成可对比的时间截面
核心字段职位名称、公司名称、城市、薪资区间、学历要求、经验要求、岗位描述、技能标签、公司规模、所属行业、发布时间、来源平台、采集时间
合规边界遵守 robots 协议与平台条款，限速低频采集；仅采集公开岗位信息，不涉及求职者个人隐私；仅用于学习研究，不商用、不转售

字段标准化规则：薪资统一折算为"月薪中位数（元/月）"，"面议"单列不参与均值计算；学历映射为大专 / 本科 / 硕士及以上三级；经验映射为应届 / 1–3 年 / 3–5 年 / 5 年以上四档。

4项目预期分析问题

#业务问题分析思路预期产出
Q1岗位的区域分布与薪资差异按城市分组统计岗位数量与薪资中位数，结合箱线图观察离散程度城市需求—薪资四象限图，锁定优先投递城市
Q2学历与经验门槛的真实结构统计学历、经验要求的分布占比，交叉分析不同学历对应的薪资水位门槛结构表；量化大专学历可争取的岗位池占比
Q3城市、学历、经验对薪资的影响权重以月薪中位数为因变量做分组对比与多变量线性回归薪资影响因素排序，形成可解释的预期模型
Q4企业最常要求哪些技能与组合对岗位描述分词并匹配自定义技能词典，统计词频与技能共现高频技能 TOP 20、共现矩阵、必备 + 加分技能清单
Q5细分岗位方向的需求与薪资差异按职位名称聚类为数仓 / 数开 / 数据分析 / 平台运维四类对比细分赛道对比表，明确优先切入方向

5项目局限性说明

  1. 样本覆盖偏差：受平台反爬与频率限制，样本以公开列表页可见岗位为主，未覆盖内推、猎头等隐性渠道。
  2. 时效性局限：招聘信息动态更新，结果为特定时间截面快照，不代表长期趋势或实时行情。
  3. 薪资口径误差：原始薪资多为区间值且部分含绩效、年终奖或"面议"，标准化后与实发薪酬存在偏差。
  4. 文本提取误差：岗位描述表述不规范，技能标签依赖分词词典，存在漏提、误提及同义词归并不足。
  5. 供需视角单一：仅反映企业招聘端需求，不含求职者供给与录取率，无法直接推断竞争激烈程度。
  6. 因果解释受限：基于观察性数据，仅能说明相关关系，不能断言学历或技能与薪资存在因果。
  7. 合规约束：采集规模受平台条款限制，样本量扩张存在上限，不具备商业数据服务的完备性。
