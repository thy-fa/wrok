大数据招聘岗位 · 数据采集方案

求职作品集项目 · 数据采集层设计

适用：专科 · 大数据技术专业 · 大三 技术栈：Python · requests · BeautifulSoup 存储：CSV

1推荐可采集的公开数据源

按"风险从低到高"排序，建议学生优先用公开数据集练手，再谨慎尝试真实站点。

数据源类型难度/风险说明
Kaggle 数据集公开数据集低"Data Science Job Salaries"等，可直接下载，零法律风险，适合做分析原型
和鲸社区 heywhale公开数据集低含国内互联网/招聘类数据集，中文语境更贴近本项目
阿里云天池赛题数据集低部分招聘赛题提供结构化数据，省去采集环节
51job 前程无忧招聘平台中页面结构相对规律，需处理分页与编码；务必遵守 robots 与频率限制
智联招聘招聘平台中含半公开 JSON 接口，可优先尝试接口而非整页解析
BOSS直聘 / 拉勾招聘平台高反爬强、需登录或加密参数，不推荐新手，易触发封禁与合规问题
国家大学生就业服务平台政府公开低官方就业数据/报告，权威且合规，适合做对比验证
建议路线：先用 Kaggle / 和鲸数据集完成"清洗—分析—可视化"全流程，证明分析能力；再把真实站点作为"数据采集实践"单独展示，并明确标注合规措施。

2需要采集的字段清单

字段（英文键）中文说明 / 采集要点
job_title职位名称如"大数据开发工程师"，用于岗位分类
company_name公司名称用于公司规模/行业聚合
city工作城市统一到城市级（如"北京"），便于区域分析
salary_text薪资原文保留原始区间文本，如"15-25K·13薪"
salary_min / salary_max薪资下限/上限清洗时从原文解析出数值（单位统一为 K/月）
education学历要求归一化为：大专 / 本科 / 硕士 / 不限
experience经验要求归一化为：1年以内 / 1-3年 / 3-5年 / 5年以上
company_size公司规模如"100-499人"
industry所属行业如"互联网/电商"
skills技能标签从岗位描述中用分词/关键词提取，逗号分隔
job_description岗位描述原始文本，用于词频与共现分析
source数据来源记录站点域名，便于溯源
crawl_time采集时间自动生成时间戳，标识数据截面

3Python 采集核心代码框架

基于 requests + BeautifulSoup，已内置 robots 校验、请求重试、频率控制和 CSV 落库。选择器为占位示例，需用浏览器开发者工具按真实页面替换（代码中已用 TODO 标注）。

"""
大数据招聘岗位数据采集框架（教学版）
技术栈：requests + BeautifulSoup(bs4) + csv
【重要合规声明】
1. 仅供学习交流，禁止商业用途或高频批量抓取。
2. 运行前请阅读目标网站的 robots.txt 与用户协议。
3. 仅采集公开岗位信息，严禁采集个人隐私数据。
4. 控制请求频率，避免对服务器造成压力。
"""

import os, time, random, csv
from typing import Optional, List, Dict
from urllib.parse import urlparse
from urllib.robotparser import RobotFileParser
import requests
from bs4 import BeautifulSoup

# ---------- 0. 基础配置 ----------
BASE_URL = "https://example.com/jobs/search"   # 替换为目标站点搜索页
HEADERS = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) ...",
    "Accept-Language": "zh-CN,zh;q=0.9",
}
MIN_DELAY, MAX_DELAY = 2.0, 4.0   # 请求间隔（秒），随机抖动
MAX_PAGES = 10                    # 学生练习建议小范围
RETRIES = 3
OUTPUT_FILE = "jobs.csv"

# ---------- 1. robots.txt 合规校验 ----------
def can_fetch(url: str) -> bool:
    parsed = urlparse(url)
    rp = RobotFileParser()
    rp.set_url(f"{parsed.scheme}://{parsed.netloc}/robots.txt")
    try:
        rp.read()
        allowed = rp.can_fetch(HEADERS["User-Agent"], url)
        if not allowed:
            print(f"[合规] robots.txt 禁止爬取：{url}")
        return allowed
    except Exception as e:
        print(f"[合规] 无法读取 robots.txt（{e}），默认不爬取。")
        return False

# ---------- 2. 单次请求（含重试） ----------
def fetch_page(url: str, params: Optional[Dict] = None) -> Optional[str]:
    for attempt in range(1, RETRIES + 1):
        try:
            resp = requests.get(url, params=params,
                                headers=HEADERS, timeout=10)
            resp.encoding = resp.apparent_encoding  # 自动识别中文编码
            if resp.status_code == 200:
                return resp.text
            print(f"[重试 {attempt}] 状态码 {resp.status_code}")
        except requests.RequestException as e:
            print(f"[重试 {attempt}] 请求异常：{e}")
        time.sleep(random.uniform(MIN_DELAY, MAX_DELAY))
    return None

# ---------- 3. 页面解析（bs4 提取字段） ----------
def parse_jobs(html: str) -> List[Dict]:
    soup = BeautifulSoup(html, "html.parser")
    records: List[Dict] = []
    # TODO: 替换为真实岗位卡片选择器，如 soup.select('.job-card')
    job_cards = soup.select("div.job-item")
    for card in job_cards:
        # TODO: 按真实结构替换每个字段的选择器
        title = card.select_one(".job-title")
        company = card.select_one(".company-name")
        city = card.select_one(".city")
        salary = card.select_one(".salary")
        record = {
            "job_title": title.get_text(strip=True) if title else "",
            "company_name": company.get_text(strip=True) if company else "",
            "city": city.get_text(strip=True) if city else "",
            "salary_text": salary.get_text(strip=True) if salary else "",
            "source": urlparse(BASE_URL).netloc,
            "crawl_time": time.strftime("%Y-%m-%d %H:%M:%S"),
        }
        records.append(record)
    return records

# ---------- 4. 保存为 CSV ----------
def save_to_csv(records: List[Dict], filename: str = OUTPUT_FILE) -> None:
    if not records:
        return
    fieldnames = records[0].keys()
    write_header = not os.path.exists(filename)
    # utf-8-sig 编码：保证 Excel 打开中文不乱码
    with open(filename, "a", newline="", encoding="utf-8-sig") as f:
        writer = csv.DictWriter(f, fieldnames=fieldnames)
        if write_header:
            writer.writeheader()
        writer.writerows(records)

# ---------- 5. 主流程 ----------
def main() -> None:
    total = 0
    for page in range(1, MAX_PAGES + 1):
        if not can_fetch(BASE_URL):
            print("[跳过] 站点未被 robots 允许，停止采集。")
            break
        html = fetch_page(BASE_URL, params={"keyword": "大数据", "page": page})
        if not html:
            break
        records = parse_jobs(html)
        if not records:
            break
        save_to_csv(records)
        total += len(records)
        time.sleep(random.uniform(MIN_DELAY, MAX_DELAY))
    print(f"[完成] 共采集 {total} 条，保存于 {OUTPUT_FILE}")

if __name__ == "__main__":
    main()

学生调试提示：先把 BASE_URL 换成目标站点，用浏览器"检查"定位岗位卡片的真实 CSS 选择器，替换 TODO 处；首次运行时将 MAX_PAGES 设为 1~2 页验证解析是否正确，再逐步放量。完整可运行版本见随附文件 job_crawler_framework.py。

4采集爬虫规范（频率 / robots / 法律风险）

① 频率控制

  • 每两次请求间隔 2–5 秒随机休眠（代码已内置 time.sleep(random.uniform(...))）。
  • 单次采集控制页数（建议 ≤ 50 页 / 站点），避免短时高并发冲击服务器。
  • 设置真实、稳定的 User-Agent，不伪造、不频繁更换。

② 遵守 robots 协议

  • 采集前访问 目标站点/robots.txt，确认目标路径未被 Disallow。
  • 代码已用 RobotFileParser 自动校验，被禁止时主动跳过。
  • 尊重 Crawl-delay 指令（若站点声明）。

③ 规避法律风险

  • 仅采集公开岗位信息，严禁抓取求职者简历等个人信息，遵守《个人信息保护法》。
  • 数据仅用于学习研究，不在公开作品集中泄露企业未公开商业数据，不用于商用或转售。
  • 不绕过登录、付费墙或加密校验；不采用分布式代理池规避封禁。
  • 遵守《网络安全法》《数据安全法》，不对目标服务器造成实质性负担（避免构成拒绝服务）。
  • 在作品集/报告中主动声明数据来源与合规措施，体现职业素养。

5数据存储方案：保存为 CSV

采用轻量、通用、无需数据库的 CSV 方案，契合学生项目与后续 Pandas 分析。

  • 编码：使用 utf-8-sig，保证 Excel 直接打开中文不乱码（关键坑点）。
  • 写入模式：open(..., "a") 追加；文件不存在时写表头，存在时仅追加数据，支持断点续采。
  • 字段对齐：以首条记录键为表头，所有记录字段保持一致，便于后续 pd.read_csv() 直接分析。
  • 进阶（可选）：数据量增大后，可改为 SQLite 或 MySQL 去重存储；分析阶段再用 pandas 读取做清洗。
