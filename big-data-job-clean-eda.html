0输入与前提

原始数据 jobs.csv 来自采集层，建议包含字段：job_title, company_name, city, salary_text, education, experience, company_size, industry, skills, job_description, source, crawl_time。若列名不同，请在脚本中对应修改。编码统一用 utf-8-sig 读取，避免中文乱码。

1数据清洗步骤（四类）

1.1 去重

  • 整行去重：drop_duplicates() 清除完全重复记录。
  • 业务主键去重：按 job_title+company_name+city+salary_text 去重，避免同一岗位被多页/多源重复抓取。
# 1) 去重：整行去重 + 业务主键去重
df = df.drop_duplicates()
df = df.drop_duplicates(
    subset=["job_title","company_name","city","salary_text"], keep="first")

1.2 缺失值处理

  • 先用 df.isna().sum() 量化各字段缺失。
  • 技能/描述补空串；学历/经验/行业/规模补"未知"占位，保留样本用于非该类分析。
  • 薪资缺失（"面议"/空）在解析后标为 NaN，薪资类分析自动剔除，不强行填充以免失真。
# 2) 查看缺失 + 文本类缺失补默认
print(df.isna().sum())
df["skills"]        = df.get("skills","").fillna("")
df["education"]     = df["education"].fillna("未知")
df["experience"]    = df["experience"].fillna("未知")
df["industry"]      = df["industry"].fillna("未知")

1.3 字段类型转换（核心）

  • 薪资：从 salary_text（如"15-25K·13薪""20-30万/年"）解析出 salary_min/max，统一换算为 K/月，并求 salary_avg。
  • 经验：解析为最低年限数值 exp_min（应届/不限→0）。
  • 学历：映射为有序数值 edu_level（大专=2、本科=3…），便于按层级比较。
  • 城市：从"城市·区"提取 city_clean。
  • 时间：pd.to_datetime 统一时间类型。
# 3) 薪资解析：原文 -> (min,max) 统一为 K/月
def parse_salary(text):
    s = str(text).replace(" ","").strip()
    if "面议" in s or s == "":
        return (np.nan, np.nan)
    is_wan  = "万" in s      # 万 -> ×10 换算 K
    is_year = "年" in s      # 年薪 -> /12 换算月
    m = re.search(r"(\d+\.?\d*)\s*[-~到至]\s*(\d+\.?\d*)", s)
    if m:
        lo, hi = float(m.group(1)), float(m.group(2))
    else:
        m2 = re.search(r"(\d+\.?\d*)", s)
        if not m2: return (np.nan, np.nan)
        lo = hi = float(m2.group(1))
    factor = 10 if is_wan else 1
    lo, hi = lo*factor, hi*factor
    if is_year: lo, hi = lo/12, hi/12
    return (round(lo,1), round(hi,1))

df[["salary_min","salary_max"]] = df["salary_text"].apply(
    lambda x: pd.Series(parse_salary(x)))
df["salary_avg"] = (df["salary_min"] + df["salary_max"]) / 2
df["exp_min"]    = df["experience"].apply(parse_experience)
df["edu_level"]  = df["education"].apply(parse_education)
df["city_clean"] = df["city"].apply(clean_city)

1.4 异常值处理

  • 薪资：保留 0 < 月薪 ≤ 200K（单位 K/月），剔除"面议"未解析项与极端值；修正 min>max 的颠倒记录。
  • 经验：剔除 exp_min < 0 或 > 30 的明显异常。
  • 说明：薪资高度右偏，域值规则比 IQR 更稳；如需保守可叠加 IQR 法。
# 4) 异常值：0 < 月薪 <= 200K；修正 min>max；经验 0~30 年
df = df[(df["salary_max"] > 0) & (df["salary_max"] <= 200)]
bad = df["salary_min"] > df["salary_max"]
df.loc[bad, ["salary_min","salary_max"]] = df.loc[bad, ["salary_max","salary_min"]].values
df = df[(df["exp_min"] >= 0) & (df["exp_min"] <= 30)]

2探索性分析维度（描述统计 + 分组统计）

2.1 描述统计（整体水位）

分析做法业务含义
数值字段 describedf[["salary_avg","exp_min","edu_level"]].describe()掌握薪资均值/中位数/离散度、经验与学历整体水位，判断是否需对数变换
城市需求量 Top10value_counts().head(10)识别高需求城市集群，指导求职地域选择
学历 / 经验分布value_counts()刻画岗位门槛画像，定位目标人群（如"本科+1-3年"为主力）

2.2 分组统计（对比与归因）

分析做法业务含义
城市 × 平均薪资groupby("city_clean")["salary_avg"].agg(["count","mean","median"])，过滤样本<20区域薪资差异，发现高薪高地（如一线 vs 新一线）
学历 × 薪资groupby("edu_level")量化学历溢价，验证"本科是否为薪酬拐点"
经验 × 薪资groupby("exp_min")经验溢价曲线，判断"几年经验性价比最高"
行业 × 薪资/需求groupby("industry")细分赛道选择，找"高薪且高需求"行业
技能词频 Top20按分隔符 split+explode 后 value_counts()构建核心技能图谱，明确学习重点（如 Python/SQL/Spark）
# 分组示例：城市 vs 薪资（过滤小样本城市）
city_salary = df.groupby("city_clean")["salary_avg"].agg(["count","mean","median"])
city_salary = city_salary[city_salary["count"] >= 20].sort_values("mean", ascending=False)

# 技能词频 Top20
skill_series = df["skills"].str.split(r"[,，、/]").explode().str.strip()
skill_series = skill_series[skill_series != ""]
print(skill_series.value_counts().head(20))
每一步 EDA 都对应一个"业务问题"：需求分布→去哪找工；薪资分组→值多少钱；技能词频→学什么。清洗层保证这些结论可信，EDA 层把数据翻译成决策。
